## 2. Tecnologías y herramientas que aparecen en el material

### Frontend
- Node.js.
- Vue (Vue 3 según el contexto configurado para el agente) y `create-vue`.
- Vite y PrimeVue según el stack técnico que indicó el usuario.
- JetBrains WebStorm.
- JSON Server para simular una API en ejercicios frontend.
- Postman para solicitudes y pruebas HTTP.

### Backend
- .NET / ASP.NET Core.
- Microsoft Visual Studio Community Edition y JetBrains Rider.
- Entity Framework Core según el stack técnico indicado en el prompt.
- MySQL Server Community Edition y MySQL Workbench.
- PostgreSQL también aparece en las semanas de backend del cuadro de actividades.

**Cuidado con el alcance:** el backend de ejemplo `CatchUpPlatform` usa MySQL y .NET 10. El hecho de que el cuadro mencione PostgreSQL no significa que `CatchUpPlatform` soporte ambos proveedores.

### Modelado, gestión y diseño
- Pivotal Tracker y Trello para gestión/seguimiento de tareas.
- UXPressia para artefactos de experiencia de usuario/personas y journeys.
- Miro y Lucidchart para diagramas y colaboración visual.
- Figma / Adobe XD para diseño de interfaz.
- Structurizr y PlantUML para documentación/diagramas de arquitectura.
- Microsoft Office 365.

## 5. Cómo debe usar el agente este contexto

1. Determina por el enunciado qué unidad/stack se está evaluando; no impongas backend .NET a una práctica de Vue/JSON Server.
2. Para actividades frontend, elige Vue/PrimeVue/JSON Server solo si se solicitan o aparecen en el ejemplo específico.
3. Para actividades backend, identifica proveedor de base de datos y arquitectura requerida en el enunciado. No supongas que siempre es MySQL o que siempre es PostgreSQL.
4. Postman sirve para validar requests, status codes, headers y payloads; incluye ejemplos cuando sean útiles.
5. Para entregables de Final Project, contempla artefactos de planificación, diseño UX/UI, arquitectura y demostración técnica cuando el enunciado los pida.
6. En semanas de exámenes, prioriza la consigna y los ejemplos usados en clase; muestra la solución y una explicación breve que permita entenderla y defenderla.
